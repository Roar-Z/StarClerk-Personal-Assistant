# StarClerk 打包说明（精简版）

## 环境
- Python 3.11 / 3.12（3.14 的 lancedb、pyarrow 轮子还不全）
- Node 18+，打包前先把前端构建出来

## 步骤
```bash
cd frontend
npm install
npm run build          # 产物在 frontend/dist，spec 会拷进包里

cd ..
pip install -r requirements.txt
pyinstaller build/starclerk.spec --noconfirm
```

产物在 `dist/StarClerk/`，双击 `StarClerk.exe` 就能跑。这是单文件夹版，不是单文件，
调试时可以直接替换 `_internal` 下的文件，也能看清楚缺了哪个 dll。

## 运行目录
首次启动会在 exe 旁边自动生成：

```
StarClerk.exe
_internal/      运行库 + 前端静态文件
data/           SQLite、LanceDB、上传的文档
logs/           app.log，按 2MB 切分
.env            模型配置，第一次启动自动生成
```

整个文件夹拷到别的机器照样能用，`data/` 删掉就是全新状态。

## 安装 / 卸载程序
两个都是免安装的单文件 exe，界面是四步向导。

```bash
pyinstaller build/uninstall.spec --noconfirm   # dist/Uninstall.exe
pyinstaller build/install.spec --noconfirm     # dist/Setup.exe
```

`Setup.exe` 会把 `dist/StarClerk/` 整个目录塞进包里（spec 里有判断，没有就打空包），
所以**先打主程序再打安装包**，顺序反了装出来是个空目录。`dist/Uninstall.exe` 存在的话
也会一起装出去，卸载时「应用和功能」里点卸载就调它。

两个 exe 都是 onefile，双击后真正跑界面的是子进程，任务管理器里会看到两个同名进程，
这个是正常的。

## 常见问题
- 杀毒软件报毒：PyInstaller 通病，加白名单即可。
- 白屏：多半是没跑 `npm run build`，或者 `_internal/frontend_dist` 没打进去。
- 起不来但没反应：看 `logs/app.log`；端口被占用会顺延，六个都占用会弹窗。
- 打不开向量库：确认 `_internal` 里有 `lance` 的 dll，别手动删。
- 系统托盘没图标：Windows 把新图标收进「隐藏的图标」里了，拖出来就行。
